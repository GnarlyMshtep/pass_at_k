# Parquet File Viewer

Interactive terminal viewer for parquet files generated by `generate_multi_plan_sft_data.py`.

## Installation

The viewer requires the following Python packages:

```bash
pip install pandas pyarrow rich readchar
```

**Note:** `readchar` is optional but highly recommended for better keyboard navigation. Without it, the viewer will use a simple command-based interface.

## Usage

### Quick Start

View a parquet file directly:

```bash
python3 view_parquet.py output/sat_2to3_multi_plan_sft.parquet
```

Or use the helper script:

```bash
./view_output.sh output/sat_2to3_multi_plan_sft.parquet
```

To list available files:

```bash
./view_output.sh
```

### Interactive Mode (with readchar installed)

**Navigation:**
- `↑` / `↓` - Navigate to previous/next row
- `Page Up` / `Page Down` - Jump by 10 rows
- `Home` / `End` - Jump to first/last row
- `1-9` - Quick jump to specific row (e.g., press `3` to jump to row 3)

**View Controls:**
- `m` - Toggle view mode (messages → metadata → all)
- `p` - Show all plans for the current sample (highlights which plan was used)
- `s` - Show dataset statistics
- `q` - Quit

### Simple Mode (without readchar)

If `readchar` is not installed, the viewer will use a simple command-based interface:

**Commands:**
- `n` - Next row
- `p` - Previous row
- `m` - Toggle view mode
- `s` - Show statistics
- `#` - Jump to row number (e.g., type `5` to jump to row 5)
- `q` - Quit
- `h` - Show help

## View Modes

1. **messages** - Shows only the conversation messages (user prompt and assistant response)
2. **metadata** - Shows only the metadata fields (data_source, ability, extra_info, etc.)
3. **all** - Shows both messages and metadata

## Features

- **Rich terminal formatting** with colors and panels
- **Dataset statistics** including unique UIDs, attempts per UID, memory usage
- **Plan visualization** showing all 4 plans with highlighting for the one used in the current sample
- **Truncation** of long content for better readability
- **Flexible navigation** with multiple ways to move through the dataset

## Examples

### Example 1: Browse the sat_2to3 dataset

```bash
python3 view_parquet.py output/sat_2to3_multi_plan_sft.parquet
```

Then use arrow keys to navigate through samples.

### Example 2: View statistics only

```bash
python3 view_parquet.py output/sat_3to3_multi_plan_sft.parquet
```

Then press `s` to see statistics.

### Example 3: Compare different attempts

Navigate to row 1, press `p` to see all plans, then use arrow keys to move to rows 2, 3, 4 (which should be the same UID with different attempts) to see how different plans were used.

## Troubleshooting

**Q: I get "ImportError: No module named 'rich'"**
A: Install dependencies with: `pip install pandas pyarrow rich readchar`

**Q: The arrow keys don't work**
A: Install readchar with: `pip install readchar`

**Q: I want to use it without interactive mode**
A: Use the `--no-interactive` flag: `python3 view_parquet.py --no-interactive <file>`

# Parquet File Viewers

Two viewers are available to explore the SFT data generated by `generate_multi_plan_sft_data.py`:

## 1. Simple Viewer (`show_parquet.py`)

Best for quick viewing and piping to other tools.

### Usage:

```bash
# Activate environment first
source venv/bin/activate

# View first 5 samples (default)
python3 sft_data/show_parquet.py sft_data/output/sat_3to3_multi_plan_sft.parquet

# View specific number of samples
python3 sft_data/show_parquet.py sft_data/output/sat_3to3_multi_plan_sft.parquet --limit 3

# Start from a specific row
python3 sft_data/show_parquet.py sft_data/output/sat_3to3_multi_plan_sft.parquet --start 10 --limit 5

# View only statistics
python3 sft_data/show_parquet.py sft_data/output/sat_3to3_multi_plan_sft.parquet --stats

# View all samples
python3 sft_data/show_parquet.py sft_data/output/sat_3to3_multi_plan_sft.parquet --all
```

## 2. Interactive Viewer (`view_parquet.py`)

Best for exploring data with keyboard navigation.

### Usage:

```bash
# Activate environment first
source venv/bin/activate

# Launch interactive viewer
python3 sft_data/view_parquet.py sft_data/output/sat_3to3_multi_plan_sft.parquet
```

### Controls:

**Simple Mode (no readchar):**
- `n` - Next row
- `p` - Previous row  
- `m` - Toggle view mode (messages/metadata/all)
- `s` - Show statistics
- `#` - Jump to row number (e.g., type `5` and Enter)
- `q` - Quit

**Interactive Mode (with readchar installed):**
- `↑/↓` - Navigate rows
- `Page Up/Down` - Jump ±10 rows
- `Home/End` - First/Last row
- `1-9` - Quick jump to row
- `m` - Toggle view (messages → metadata → all)
- `p` - Show all 4 plans for current sample
- `s` - Statistics
- `q` - Quit

## What You'll See

### Metadata Displayed:
- `attempt_num` - Which attempt (1-4) this sample represents
- `plan_used` - The specific plan used for this attempt
- `all_plans` - Indicator that 4 plans are available

### Metadata Hidden (filtered out):
- `variable_labels`, `uid`, `split`, `solution`, `raw_sat`
- `prompt_style`, `num_variables`, `num_clauses`
- `num_attempts`, `max_allowed_attempts`, `index`

### Messages:
- **USER PROMPT** - The SAT problem and task instructions
- **ASSISTANT RESPONSE** - All 4 plans + which one is used + the solution

## Dataset Statistics

Both viewers show:
- Total rows in the dataset
- Number of unique UIDs (problems)
- Attempts per UID (should be 4.0)
- Dataset columns and memory usage

## Examples

### Compare different attempts for the same problem:

```bash
# View attempts 1-4 (first 4 rows likely from same UID)
python3 sft_data/show_parquet.py sft_data/output/sat_3to3_multi_plan_sft.parquet --start 0 --limit 4
```

### View a specific sample interactively:

```bash
python3 sft_data/view_parquet.py sft_data/output/sat_3to3_multi_plan_sft.parquet
# Then press '5' to jump to row 5, 'p' to see all plans
```

### Get quick stats:

```bash
python3 sft_data/show_parquet.py sft_data/output/sat_2to3_multi_plan_sft.parquet --stats
```

## Files Available

- `sft_data/output/sat_2to3_multi_plan_sft.parquet` - 2-3 variable SAT problems
- `sft_data/output/sat_3to3_multi_plan_sft.parquet` - 3-variable SAT problems (shown in your terminal)
